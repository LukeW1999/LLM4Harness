## CRITICAL: Bounding scalar inputs to prevent CBMC UNKNOWN

CBMC uses bounded model checking. If you pass unbounded scalar inputs (e.g., `size_t capacity = nondet_size_t()` with no constraint), CBMC must explore an infinite state space and returns UNKNOWN — not because your assertion is wrong, but because the computation budget is exceeded.

**Rule: Every scalar nondet variable must be immediately bounded with `__CPROVER_assume`.**

```c
// WRONG — causes CBMC UNKNOWN due to state space explosion:
size_t capacity = nondet_size_t();
size_t length = nondet_size_t();

// CORRECT — bounded scalars let CBMC complete verification:
size_t capacity = nondet_size_t();
__CPROVER_assume(capacity > 0 && capacity <= MAX_BUFFER_SIZE);

size_t length = nondet_size_t();
__CPROVER_assume(length <= capacity);
```

Available bounding constants (defined in Makefile):
- `MAX_BUFFER_SIZE` — maximum byte buffer capacity
- `MAX_ITEM_SIZE` — maximum item size in array lists
- `MAX_INITIAL_ITEM_ALLOCATION` — maximum initial allocation count
- `MAX_LINKED_LIST_ITEM_ALLOCATION` — maximum linked list length

**If CBMC returns UNKNOWN, the first thing to check is: are all scalar inputs bounded?**

## Standard Harness Pattern

```c
void aws_XXX_harness() {
    /* 1. Declare and bound data structures */
    struct aws_XXX s;
    __CPROVER_assume(aws_XXX_is_bounded(&s, MAX_XXX_SIZE));
    ensure_XXX_has_allocated_data_member(&s);
    __CPROVER_assume(aws_XXX_is_valid(&s));

    /* 2. Save old state BEFORE calling — needed for immutability checks */
    struct aws_XXX old = s;

    /* 3. Call function under test */
    int result = aws_XXX_function(&s, ...);

    /* 4. Assert postconditions for BOTH success and failure paths */
    if (result == AWS_OP_SUCCESS) {
        assert(/* what changed */);
    } else {
        assert(/* struct unchanged on failure */);
    }

    /* 5. Assert fields that must NOT change regardless of result */
    assert(s.allocator == old.allocator);
    assert(s.capacity == old.capacity);
    /* ... one assert per unchanged field ... */

    /* 6. Assert validity invariant always holds */
    assert(aws_XXX_is_valid(&s));
}
```

## CRITICAL: Read the function signature carefully before writing

**Return value vs output pointer** — AWS functions use two different styles:
- `size_t aws_add_size_saturating(size_t a, size_t b)` → result is the **return value**: `r = aws_add_size_saturating(a, b)`
- `int aws_round_up_to_power_of_two(size_t n, size_t *result)` → result via **output pointer**: `aws_round_up_to_power_of_two(n, &result)`
- `struct aws_byte_buf aws_byte_buf_from_array(const void *bytes, size_t len)` → returns a **struct by value**: `buf = aws_byte_buf_from_array(ptr, len)`

Always call the function exactly as its signature requires.

**Linked list harnesses** — always use `ensure_linked_list_is_allocated` to initialize:
```c
struct aws_linked_list list;
ensure_linked_list_is_allocated(&list, MAX_LINKED_LIST_ITEM_ALLOCATION);
```
The linked list has NO `length` field. Access nodes via `list.head.next` and `list.tail.prev`.
After push_back/push_front, assert the pointer linkage explicitly:
```c
assert(list.tail.prev == &node);   // push_back: tail now points to new node
assert(node.prev == old_last);     // new node links back to previous last
```

**CRITICAL — Four categories of postconditions you must cover:**

### 1. Changed fields (from Doxygen)
Assert what the function explicitly guarantees changes:
```c
assert(buf.len == old.len + 1);   // "len increases by 1"
assert(result == a + b);          // "returns the sum"
```

### 2. Unchanged fields (implied — Doxygen rarely lists these)
For EVERY field not mentioned as changing, add an explicit assert:
```c
assert(buf.capacity == old.capacity);    // capacity not mentioned → unchanged
assert(buf.allocator == old.allocator);  // allocator not mentioned → unchanged
assert(buf.buffer == old.buffer);        // pointer not mentioned → unchanged
```

### 3. Both return paths
Always cover success AND failure:
```c
if (result == AWS_OP_SUCCESS) { assert(/* success postcondition */); }
else                          { assert(/* failure: struct unchanged */); }
```

### 4. Validity invariants
After the call, assert all structures remain valid:
```c
assert(aws_byte_buf_is_valid(&buf));
assert(aws_byte_cursor_is_valid(&cursor));
```
