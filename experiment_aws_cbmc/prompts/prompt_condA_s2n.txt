## Standard Harness Pattern

```c
void s2n_XXX_harness() {
    /* 1. Build a non-deterministic, structurally valid input */
    struct s2n_stuffer stuffer;
    cbmc_populate_s2n_stuffer(&stuffer);
    __CPROVER_assume(s2n_stuffer_is_valid(&stuffer));

    /* 2. Save old state BEFORE calling, for immutability and delta checks */
    struct s2n_stuffer old_stuffer = stuffer;
    struct store_byte_from_buffer old_byte;
    save_byte_from_blob(&stuffer.blob, &old_byte);

    /* 3. Call the function under test */
    int result = s2n_XXX(&stuffer, ...);

    /* 4. Assert postconditions on BOTH paths */
    if (result == S2N_SUCCESS) {
        assert(/* what the success path must have changed */);
    } else {
        assert(/* the object is unchanged on failure */);
    }

    /* 5. Assert the fields that must not change either way */
    assert(stuffer.blob.size == old_stuffer.blob.size);
    assert(stuffer.alloced == old_stuffer.alloced);
    /* ... one assert per unchanged field ... */

    /* 6. The validity invariant must still hold */
    assert(s2n_stuffer_is_valid(&stuffer));
}
```

## CRITICAL: Read the function signature carefully before writing

**Return value vs output pointer** — s2n functions use both styles:
- `int s2n_stuffer_skip_read(struct s2n_stuffer *stuffer, uint32_t n)` → status in the **return value**
- `int s2n_stuffer_read_uint8(struct s2n_stuffer *stuffer, uint8_t *u)` → data via an **output pointer**
- `void *s2n_stuffer_raw_read(struct s2n_stuffer *stuffer, uint32_t data_len)` → returns a **pointer**, which may be NULL

Call the function exactly as its signature requires.

**Stuffer fields** — a `struct s2n_stuffer` carries `blob` (the storage), `read_cursor`,
`write_cursor`, `high_water_mark`, `alloced`, `growable` and `tainted`. A harness that
checks only `write_cursor` leaves the rest unconstrained, so assert every field the
function is specified to preserve, not just the one it changes.

## Your Task

Write a complete harness. Translate the Doxygen description into assumes and asserts.

**CRITICAL — Four categories of postconditions you must cover:**

### 1. Changed fields (from Doxygen)
Assert what the function explicitly guarantees changes:
```c
assert(stuffer.read_cursor == old_stuffer.read_cursor + n);  // "advances by n"
assert(s2n_result_is_ok(result));                            // "returns success"
```

### 2. Unchanged fields (implied — Doxygen rarely lists these)
For EVERY field not mentioned as changing, add an explicit assert:
```c
assert(stuffer.blob.size == old_stuffer.blob.size);  // size not mentioned → unchanged
assert(stuffer.growable == old_stuffer.growable);    // growable not mentioned → unchanged
assert(stuffer.blob.data == old_stuffer.blob.data);  // pointer not mentioned → unchanged
```

### 3. Both return paths
Always cover success AND failure:
```c
if (result == S2N_SUCCESS) { assert(/* success postcondition */); }
else                       { assert(/* failure: struct unchanged */); }
```

### 4. Validity invariants
After the call, assert all structures remain valid:
```c
assert(s2n_stuffer_is_valid(&stuffer));
assert(s2n_blob_is_valid(&stuffer.blob));
```

## CRITICAL: assert() calls are mandatory
