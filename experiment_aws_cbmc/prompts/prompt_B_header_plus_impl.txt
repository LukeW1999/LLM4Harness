## Your Task

Write a complete CBMC harness function named `{FUNCTION_NAME}_harness()` that:

1. Declares and initializes all input variables non-deterministically (use `nondet_<type>()` for scalar types, or `malloc`/helper functions for structs with pointer members)
2. Establishes all preconditions using `__CPROVER_assume(...)`, derived from the AWS_PRECONDITION annotations in the implementation
3. Calls the function under verification
4. Asserts all postconditions using `assert(...)`, derived from the AWS_POSTCONDITION annotations and the function's documented behavior
5. Handles both the success and failure return paths
6. Saves old state before the call when asserting that inputs are not modified

## CBMC Harness Conventions

- Use `nondet_bool()`, `nondet_uint32_t()`, `nondet_uint64_t()`, `nondet_size_t()` for non-deterministic scalars
- Use `__CPROVER_assume(condition)` to constrain inputs (preconditions)
- Use `assert(condition)` to check postconditions and invariants
- For bounded data structures, use `__CPROVER_assume(aws_XXX_is_bounded(&s, MAX_SIZE, MAX_ITEM_SIZE))` before `ensure_XXX_has_allocated_data_member(&s)`
- Use `AWS_MEM_IS_READABLE` / `AWS_MEM_IS_WRITABLE` for memory accessibility constraints
- Standard includes: `<aws/common/{module}.h>` and `<proof_helpers/make_common_data_structures.h>`

## Output Format
