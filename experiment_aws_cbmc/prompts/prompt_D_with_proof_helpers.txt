## Standard Harness Pattern

```c
void aws_XXX_harness() {
    /* 1. Declare data structure(s) on stack */
    struct aws_XXX s;

    /* 2. Bound the structure (limits CBMC state space) */
    __CPROVER_assume(aws_XXX_is_bounded(&s, MAX_XXX_SIZE));

    /* 3. Allocate pointer members */
    ensure_XXX_has_allocated_data_member(&s);

    /* 4. Assume validity precondition */
    __CPROVER_assume(aws_XXX_is_valid(&s));

    /* 5. Save old state (for checking immutability) */
    struct aws_XXX old = s;
    struct store_byte_from_buffer old_byte;
    save_byte_from_array((uint8_t *)s.data, s.current_size, &old_byte);

    /* 6. Assume function-specific preconditions */
    __CPROVER_assume(specific_precondition);

    /* 7. Call function under test */
    int result = aws_XXX_function(&s, ...);

    /* 8. Assert postconditions (both branches) */
    if (result == AWS_OP_SUCCESS) {
        assert(postcondition_on_success);
    }
    assert(aws_XXX_is_valid(&s));  // invariant always holds
    assert_XXX_equivalence(&s, &old, &old_byte);  // if read-only
}
```

## CBMC Macro Semantics

```c
AWS_PRECONDITION(cond)  → __CPROVER_precondition(cond, ...)  [in CBMC mode]
AWS_POSTCONDITION(cond) → __CPROVER_assert(cond, ...)         [in CBMC mode]
AWS_OP_SUCCESS = 0
AWS_OP_ERR = -1
```
