## Your Task

## CBMC Harness Conventions

- Use `nondet_bool()`, `nondet_uint32_t()`, `nondet_uint64_t()`, `nondet_size_t()` for non-deterministic scalars
- Use `__CPROVER_assume(condition)` to constrain inputs (preconditions)
- Use `assert(condition)` to check postconditions
- For structs with validity predicates (e.g., `aws_byte_buf_is_valid`), use `__CPROVER_assume(aws_XXX_is_valid(&s))`
- Save old state before the call if you need to check that something is unchanged
- Handle both success (AWS_OP_SUCCESS == 0) and failure (AWS_OP_ERR == -1) branches
